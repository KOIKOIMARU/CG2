# 戦闘用の効果音

このプロジェクト向けに数式・疑似乱数から生成したオリジナル音源。
既存ゲームの音声、外部サンプル、第三者の録音は使用していない。
再生成: `project/tools/GenerateCombatSounds.py`（Python標準ライブラリのみ）。

- shot / charge: 通常弾・チャージ弾の発射
- hit / destroy: 命中・撃破（撃破時は命中音を重ねない）
- damage / dodge: 自機被弾・ジャスト回避
- fever / clear / fail: フィーバー開始・クリア・ゲームオーバー

48kHz・16bit・モノラルPCM。再生側でステレオへ変換して使用。
ピークは約-7.5dBFS。同じ音の最短発音間隔と同時発音数を制限し、
通常弾の音量は抑えて命中・撃破を聞き分けられる構成にしている。
音色・音量は初回調整であり、実際のスピーカーやヘッドホンで好みを確認して調整する。
