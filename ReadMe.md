# CG4 評価課題2 加点要素ショーケース

## 加点要素

通常起動すると、以下の加点要素をまとめた専用ショーケースを直接表示します。`B` で骨表示、`G` でGPUパーティクルの放出をON/OFF、`F2` または `Esc` でタイトルへ戻ります。実装した加点要素の合計は100点です。

### Skinningモデルの表示（20点）

- `simpleSkin/simpleSkin.gltf` と `human/walk.gltf` を表示します。
- glTFからジョイント、ウェイト、逆バインドポーズ行列を読み込み、アニメーションした姿勢を頂点へ適用しています。

### Compute Shaderによるスキニング（10点）

- `project/shaders/Skinning.CS.hlsl` で頂点の位置と法線をGPU上でスキニングしています。
- 入力頂点、頂点インフルエンス、行列パレットをStructuredBufferとして渡し、出力頂点をUAVへ書き込んで描画しています。
- Dispatch後はUAVバリアと頂点バッファ用リソースステートへの遷移を行っています。

### MultiMesh & MultiMaterial対応（5点）

- `multiMesh.obj` と `multiMaterial.obj` をAssimpで読み込み、メッシュ単位の描画範囲とマテリアル番号を保持しています。
- 各描画範囲で対応するテクスチャへ切り替えて描画します。

### Animation補間（5点）

- 平行移動と拡縮は線形補間、回転はQuaternionのSlerpでキーフレーム間を補間しています。
- ショーケースのスキニングモデルで補間結果を連続再生します。

### 骨のデバッグ表示（10点）

- アニメーション中の各ジョイントを水色の球、親子関係を橙色のボーンとして表示します。
- モデルのワールド行列と毎フレーム更新されるスケルトン行列に追従します。

### 武器を手に持たせる（10点）

- `human/walk.gltf` の `mixamorig:RightHand` と `mixamorig:RightForeArm` のワールド座標を毎フレーム取得します。
- 刀身、鍔、柄の3パーツで構成した武器を右手へ接続し、歩行アニメーション中の腕の向きと位置へ追従させます。

### 手からパーティクルを出す（10点）

- `mixamorig:LeftHand` のワールド座標を放出点として、水色、紫、桃色の粒を連続放出します。
- 32個の固定プールを初期化時に生成し、寿命、速度、拡縮をCPUで更新します。実行中の動的確保は行いません。
- 手の粒子は安定した `Object3d` 描画を使用し、下記のGPUパーティクルとは独立して動作します。

### GPU Particle機能拡張（30点）

- 水色の噴水と桃色・金色のスパークを、独立した2つのEmitter／ParticleGroupとして同時に動かします。
- `project/shaders/EmitParticle.CS.hlsl` を64 threadsで並列実行し、放出数に応じてDispatch数を計算します。各threadがFreeListから1粒を確保するため、1 thread内の逐次ループではありません。
- Particle本体、空き番号カウンタ、FreeListをUAVのStructuredBufferとしてGPU上で初期化、放出、更新し、描画時は同じParticle本体をSRVとして参照します。
- 半径、方向、広がり、最小・最大色、最小・最大スケール、寿命、速度、終了時スケールをEmitterごとに設定できます。
- Compute処理間にはUAVバリア、描画前にはUAVからSRV用ステートへの遷移を行います。
- GPUパーティクルを3D描画の最後に配置し、異なるRoot Signatureを使う `Object3d` 描画との順序を明示しています。

ゲーム本編の自機噴射には接続せず、評価用ショーケース内だけで動作させています。
