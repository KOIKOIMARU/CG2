# LE3B_07_コイズミ_リョウ

## 課題内容

個人制作ゲーム内で使用している HitEffect の紹介用 ReadMe です。

本作品は、空中を進みながら敵を撃破していく 3D レールシューティングです。
プレイヤーはマウスで照準を動かし、通常弾とチャージショットで敵を倒します。
ゲーム内演出として、敵撃破、プレイヤー被弾、弾の発光に HitEffect を組み込んでいます。

## 実装している Effect

### 敵撃破エフェクト

敵に弾が命中して撃破された位置に、白熱した中心光、金色の閃光、青い残光を重ねて表示します。
単純な円の拡大だけに見えないよう、各レイヤーに別々の縦横比、回転、発生タイミング、移動量を与えています。

- 発生条件: プレイヤー弾が敵に命中し、敵を撃破した時
- 表示内容: 中心光、金色の閃光、青い残光、薄いリング状の余韻
- 目的: 命中感、撃破感、画面内での注目ポイントを強調する

### プレイヤー被弾エフェクト

敵弾がプレイヤーに命中した時、プレイヤー位置に赤い発光エフェクトを出し、同時にカメラシェイクを発生させます。
HPバーだけでなく、画面内のプレイヤー付近でも被弾が分かるようにしています。

- 発生条件: 敵弾がプレイヤーに命中した時
- 表示内容: 赤い中心光、短い赤い閃光、カメラシェイク
- 目的: 被弾のフィードバックを強め、危険状態を分かりやすくする

### 弾の発光トレイル

プレイヤー弾と敵弾に発光グローとトレイルを追加しています。
通常弾、ロックオン弾、チャージショットで色や大きさを変え、弾の強さが視覚的に分かるようにしています。

- 発生条件: プレイヤーまたは敵が弾を発射した時
- 表示内容: 弾本体、発光コア、進行方向に残るトレイル
- 目的: 弾を見やすくし、シューティングとしての手触りを強める

## 見た目の工夫

- エフェクトは ImGui の線や図形ではなく、ゲーム内の Object3D とテクスチャ付きビルボードで描画しています。
- ブルームと加算合成を組み合わせ、光っている部分が画面内で自然に目立つようにしています。
- 大量の破片や線を出しすぎず、ゲーム画面の視認性を保つように調整しています。
- 敵撃破、被弾、弾の発光で色を分け、何が起きたか分かりやすくしています。

## 操作方法

- `Enter`: タイトルからゲーム開始
- `Mouse`: 照準移動
- `Left Click`: 射撃
- `Space`: チャージショット
- `F1`: GUI表示切り替え
- `F2`: タイトルへ戻る

## 紹介動画で見せるポイント

30秒以内の紹介動画では、以下の流れで撮影すると分かりやすいです。

1. ゲーム開始後に通常弾で敵を撃破し、敵撃破 HitEffect を見せる
2. チャージショットで敵を撃破し、通常弾より強い発光とトレイルを見せる
3. 余裕があれば被弾して、赤い被弾エフェクトとカメラシェイクを見せる

## ビルド方法

Visual Studio で `project/CG2.sln` または `project/CG2.vcxproj` を開き、`Debug x64` または `Release x64` でビルドしてください。
