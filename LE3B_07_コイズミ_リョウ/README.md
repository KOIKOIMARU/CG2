# LE3B_07_コイズミ_リョウ

## 概要

個人制作ゲームに組み込んだ演出要素の紹介です。

本作品は、空中を進みながら敵を撃破していく3Dレールシューティングです。  
今回の課題では、ゲーム中の見栄えと手触りを良くするための演出を中心に実装しました。

## 実装した主な演出

- 弾の発光、長い軌跡、小さなスパーク
- チャージ弾の追尾と強めの発光
- 敵弾の赤い発光と軌跡
- 敵撃破時の爆散風エフェクト
- 被弾時のフラッシュとカメラシェイク
- ブルーム、ゲームトーン、ヴィネットなどのポストエフェクト
- HP、スコア、ウェーブ表示などのHUD

## 操作方法

- `Enter`: タイトルからゲーム開始
- `Mouse`: 照準移動
- `Space`: チャージショット
- `Shift`: 回避

## 実行方法

`実行ファイルセット/CG2.exe` を起動してください。
