# ゲーム品質の見直し

## 方針

機能の数ではなく、短い区間を遊んだときの完成度を上げる。
核は「狙って倒す → 危険を避けてつなぐ → フィーバーで押し切る」。
まず冒頭の戦闘を磨き、その基準を中盤・ボスへ広げる。時間を延ばすための待ち時間は追加しない。
ただし、本編を練習用の内容にはしない。操作習得のチュートリアルと本編の面白さの改善は分ける。

作業前のローカル保存先: `codex/checkpoint-before-opening-review-20260915` / `3c0bb58`。
既存のHUD・マテリアル・建物描画の修正を含む。外部へのプッシュは行っていない。

### チュートリアル側へ移した配置

- 最初は中央の単体。移動と連射を試せるよう、まだ敵は反撃しない。
- 次は左右2機。HPを3にして、通常弾3発とチャージ弾1発の違いを示す。
- 続いて射撃する敵1機。ここから反撃を始め、回避を使う場面を作る。
- 左右から来る移動敵で、追いかけて照準を合わせる段階へ移る。
- 3機編隊を配置し、撃破をつないでためたゲージをフィーバーに使う機会を作る。
- 初登場時のみ短い操作案内を表示。フィーバー演出中には重ねない。
- 撃破後の移動と息継ぎを並行させ、二重の待ち時間をなくした。
- フィーバー中は編隊間の進行を加速する。敵が残る戦闘中の進行停止は維持する。

### 不整合の修正

配置データ26件に対して出現管理が24件だったため、末尾2件が処理されなかった。
出現済みフラグは開始時に配置データの件数分だけ確保する方式へ変更。
本編26件・チュートリアル11件それぞれの件数に合わせる。距離順やHP等の不正値もコンパイル時に検査する。

### 確認の意味と限界

- 起動放置テスト：描画・進行の安定性を確認する。面白さの評価には使わない。
- 一時的な自動照準・射撃テスト：通常弾、チャージ弾、撃破、チェイン、ゲージ蓄積、フィーバー、次編隊への連係を確認する。
- 自動照準は人間より速く正確なので、到達時間を標準クリア時間とは扱わない。
- テスト用の自動操作は検証後に除去する。通常のゲーム操作は変更しない。
- 実プレイでは、初見で操作が分かるか、狙い直す余裕があるか、次に何をするか迷わないかを確認する必要がある。

Debug／Releaseビルドは警告0・エラー0。通常操作版で各30秒の動作確認を完走。
DebugではDebug Layer・DRED・InfoQueueの有効化と、診断警告・エラーがないことを確認した。
一時的な自動戦闘は冒頭90秒、終盤45秒を完走。配置29件目までの出現を記録した。
自動照準・射撃・フィーバー発動と検証用ログ出力は、最終ソースから除去済み。

## 次に見直す順序

1. 射撃・命中・撃破の音。連射時の音声の寿命・同時発音数を管理してから、通常弾／チャージ／撃破の音を区別する。
2. 冒頭の実プレイ結果で、敵の大きさ・滞在時間・弾速を調整。成功率だけでなく、チャージと回避を使い分ける意味を見る。
3. ステージの構図。新しい素材を大量に増やす前に、建物の高さ、開けた区間、見通し、光の変化で場面を区切る。
4. 中盤とボスへ展開。予告を見て回避し、隙に攻撃する関係を明確にする。

今回、音の実装・ステージ全体の再設計・ボスの再調整まで完了したわけではない。
「神ゲーと同等になった」「面白さが検証済み」とは評価しない。

## 自機モデルの比較（2026-09-15）

音の実装より先に、ユーザーの希望でモデルを見直した。
QuaterniusのUltimate Spaceships PackからOmen・Executioner・Zenithを導入。
Insurgentも調べたが重装艦寄りだったため候補から外し、実行用リソースには残していない。
素材の配布元・CC0・変換方法は `project/resources/free_models/player_candidates/README.md` に記録。

- 初期選択はOmen。翼の輪郭が分かりやすいため、現時点でのおすすめ候補とする。
- タイトルの「自機モデルを比較」または本編／練習中のF8で比較画面。
- 比較中はゲーム進行を固定。同一のカメラ・背景で機体を切り替え、Y軸回転で見回せる。
- 比較を閉じたら元の姿勢へ戻してプレイ再開。選択は起動中だけ保持。
- 元のSpeederも保持。HP・移動・回避・射撃・当たり判定の数値は変更しない。
- 噴射は機体別に位置だけ合わせた。既存のGPU描画・リソース状態・グループ数は変更しない。
- Executionerは中央2基を巡航噴射として表示し、外側ノズルは発光させていない。
- 頂点は比率を保って共通範囲へ縮小。画像はミップ付きDDSに事前変換し、切り替え時に再ロードしない。

検証: Debug/Releaseとも警告0・エラー0。
実画面で4機の切り替え、109度の回転、姿勢復帰、通常プレイ再開を確認。
比較中はHP100・背景が固定され、再開後は通常通り被弾・ゲームオーバーまで進行した。
Debug 20秒: `generated/smoke-tests/debug-20260915-090416.log`。
Release 30秒: `generated/smoke-tests/release-20260915-090451.log`（1770フレーム）。
実画面のD3D12診断: `generated/smoke-tests/player-candidates-final-visible.log`。警告・エラーなし。
