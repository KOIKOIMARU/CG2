# ゲーム品質の見直し

## 方針

機能の数ではなく、短い区間を遊んだときの完成度を上げる。
核は「狙って倒す → 危険を避けてつなぐ → フィーバーで押し切る」。
まず冒頭の戦闘を磨き、その基準を中盤・ボスへ広げる。時間を延ばすための待ち時間は追加しない。
ただし、本編を練習用の内容にはしない。操作習得のチュートリアルと本編の面白さの改善は分ける。

作業前のローカル保存先: `codex/checkpoint-before-opening-review-20260915` / `3c0bb58`。
既存のHUD・マテリアル・建物描画の修正を含む。外部へのプッシュは行っていない。

## 現在の構成：本編とチュートリアルを分離（2026-09-15）

ユーザーから「本編をチュートリアルのようにしないで分けてほしい」と指摘があったため、
前回の練習用配置は本編には採用せず、専用の入口へ分離した。

- タイトルの「ゲーム開始 [Enter]」：変更前の本編26件の敵配置・HP・攻撃設定。
- タイトルの「チュートリアル [T]」：練習用11件と操作案内。ボス戦へは進まない。
- チュートリアル終了時は専用の終了画面。本編のクリア扱いやランク評価にしない。
- タイトルに戻って本編へ入ると、HP・スコア・ゲージ・敵の出現状況は新しく初期化される。
- 撃破後の二重待ちの解消と、末尾2件が出ない不具合修正は本編にも残す。

分離後の確認：Debug／Releaseとも警告0・エラー0。
実画面で「チュートリアル選択 → 被弾による練習終了 → タイトル → 本編選択」を確認し、
本編でHPが初期化され、練習表示・案内が出ないことを確認した。
本編の敵配置データは `3c0bb58` と一致する。
スモークテストは選択されたモードも照合し、DebugのチュートリアルとReleaseの両モードで各20秒を確認。
画面遷移の診断記録：`generated/smoke-tests/tutorial-separation-debug-visible.log`。

### チュートリアル側へ移した配置

- 最初は中央の単体。移動と連射を試せるよう、まだ敵は反撃しない。
- 次は左右2機。HPを3にして、通常弾3発とチャージ弾1発の違いを示す。
- 続いて射撃する敵1機。ここから反撃を始め、回避を使う場面を作る。
- 左右から来る移動敵で、追いかけて照準を合わせる段階へ移る。
- 3機編隊を配置し、撃破をつないでためたゲージをフィーバーに使う機会を作る。
- 初登場時のみ短い操作案内を表示。フィーバー演出中には重ねない。
- 撃破後の移動と息継ぎを並行させ、二重の待ち時間をなくした。
- フィーバー中は編隊間の進行を加速する。敵が残る戦闘中の進行停止は維持する。

### 不整合の修正

配置データ26件に対して出現管理が24件だったため、末尾2件が処理されなかった。
出現済みフラグは開始時に配置データの件数分だけ確保する方式へ変更。
本編26件・チュートリアル11件それぞれの件数に合わせる。距離順やHP等の不正値もコンパイル時に検査する。

### 確認の意味と限界

- 起動放置テスト：描画・進行の安定性を確認する。面白さの評価には使わない。
- 一時的な自動照準・射撃テスト：通常弾、チャージ弾、撃破、チェイン、ゲージ蓄積、フィーバー、次編隊への連係を確認する。
- 自動照準は人間より速く正確なので、到達時間を標準クリア時間とは扱わない。
- テスト用の自動操作は検証後に除去する。通常のゲーム操作は変更しない。
- 実プレイでは、初見で操作が分かるか、狙い直す余裕があるか、次に何をするか迷わないかを確認する必要がある。

以下は分離前の試作を確認した記録であり、現在の本編のプレイ時間・難易度の評価には使わない。
Debug／Releaseビルドは警告0・エラー0。通常操作版で各30秒の動作確認を完走。
DebugではDebug Layer・DRED・InfoQueueの有効化と、診断警告・エラーがないことを確認した。
一時的な自動戦闘は冒頭90秒、終盤45秒を完走。配置29件目までの出現を記録した。
自動照準・射撃・フィーバー発動と検証用ログ出力は、最終ソースから除去済み。

## 次に見直す順序

1. 射撃・命中・撃破の音。連射時の音声の寿命・同時発音数を管理してから、通常弾／チャージ／撃破の音を区別する。
2. 冒頭の実プレイ結果で、敵の大きさ・滞在時間・弾速を調整。成功率だけでなく、チャージと回避を使い分ける意味を見る。
3. ステージの構図。新しい素材を大量に増やす前に、建物の高さ、開けた区間、見通し、光の変化で場面を区切る。
4. 中盤とボスへ展開。予告を見て回避し、隙に攻撃する関係を明確にする。

今回、音の実装・ステージ全体の再設計・ボスの再調整まで完了したわけではない。
「神ゲーと同等になった」「面白さが検証済み」とは評価しない。

## 自機モデルの比較（2026-09-15）

音の実装より先に、ユーザーの希望でモデルを見直した。
QuaterniusのUltimate Spaceships PackからOmen・Executioner・Zenithを導入。
Insurgentも調べたが重装艦寄りだったため候補から外し、実行用リソースには残していない。
素材の配布元・CC0・変換方法は `project/resources/free_models/player_candidates/README.md` に記録。

- 初期選択はOmen。翼の輪郭が分かりやすいため、現時点でのおすすめ候補とする。
- タイトルの「自機モデルを比較」または本編／練習中のF8で比較画面。
- 比較中はゲーム進行を固定。同一のカメラ・背景で機体を切り替え、Y軸回転で見回せる。
- 比較を閉じたら元の姿勢へ戻してプレイ再開。選択は起動中だけ保持。
- 元のSpeederも保持。HP・移動・回避・射撃・当たり判定の数値は変更しない。
- 噴射は機体別に位置だけ合わせた。既存のGPU描画・リソース状態・グループ数は変更しない。
- Executionerは中央2基を巡航噴射として表示し、外側ノズルは発光させていない。
- 頂点は比率を保って共通範囲へ縮小。画像はミップ付きDDSに事前変換し、切り替え時に再ロードしない。

検証: Debug/Releaseとも警告0・エラー0。
実画面で4機の切り替え、109度の回転、姿勢復帰、通常プレイ再開を確認。
比較中はHP100・背景が固定され、再開後は通常通り被弾・ゲームオーバーまで進行した。

## 一通り遊べる流れと戦闘音の整備（2026-09-24）

先生から示された「開始からクリアまで遊べる」「操作に使い分けがある」
「敵のバリエーションとリアクションがある」という観点で、実装と実行を確認した。
既存の敵配置26件・8種類の行動・ボス2段階と3攻撃、本編／練習の分離は維持。
今回の変更前は `7116fa9` / `codex/checkpoint-before-playability-20260924` に保存済み。
この保存には前回までのOmen採用・チュートリアル分離の変更も含む。外部へのプッシュはしていない。

### 今回追加した内容

- タイトルで勝利条件、照準、連射／チャージ、回避、フィーバー、ボスの反撃機会を案内。
- 本編・練習中のHで操作案内を開閉。案内を開いてもゲームは進むことを明記。
- 結果画面に「再挑戦」「タイトル」ボタンを追加。Rでも同じモードへ再挑戦できる。
- 結果表示中は戦闘HUDを隠し、結果と次の操作を読みやすくした。
- 通常弾／チャージ弾、命中／撃破、被弾、ジャスト回避、フィーバー、成功／失敗の9効果音。
- 音は数式から生成したオリジナルPCM。外部素材や既存ゲームの音は使用していない。
- 初期化時に合計20音声枠を確保。同じ音の連続発音を制限し、満杯なら追加生成しない。
- シーン終了時は再生ボイスを破棄してから波形を解放。音声初期化失敗時もゲームは継続する。
- 被弾処理はPlayerの無敵フラグも確認する。HP・弾威力・回避時間そのものは変更していない。

### 検証内容と限界

Debug専用の `-Playthrough` をスモークテストへ追加した。
移動・マウス照準・射撃・回避・フィーバー・H・Rを入力データとして与える。
敵のHPを直接減らす、無敵化する、ステージを飛ばす、強制クリアする処理は使わない。
Releaseには自動操作コードが入らず、Debugでもこのオプションを指定したときだけ動く。

実行例（300秒は制限時間。再挑戦の初期化を確認した時点で正常終了する）：

```powershell
& .\project\tools\RunSmokeTest.ps1 -Configuration Debug -GameplaySeconds 300 -Playthrough
```

最初の通し確認：全26配置とボスを撃破、逃走0、フィーバー2回、残HP34。
射撃111回・命中84回・効果音203回。音声枠は20のまま増加しない。
結果画面からRで再挑戦し、HP100・スコア0・ゲージ0・未出現状態・音声20枠を確認。
ログ：`generated/smoke-tests/debug-20260924-065408.log`。
D3D12 Debug Layer・DRED・InfoQueue有効、警告・エラーなし。

実画面でもタイトルの説明、敗北結果、再挑戦、タイトル復帰を確認した。
マウス操作の診断記録：`generated/smoke-tests/playability-20260924-visible.log`。
自動照準は人間より正確なので、この結果を初見難易度・面白さ・標準クリア時間の保証には使わない。
音の同時発音と再生処理は確認したが、音色・音量は実機で聞いて好みを合わせる初回調整である。

最終確認：Debug／Releaseとも警告0・エラー0。
Debugの再通し検証でも同じ撃破数と再挑戦初期化に成功し、Hの案内開閉も検証した。
記録：`debug-20260924-070212.log`（D3D12警告・エラーなし）。
通常Releaseの30秒テスト：`release-20260924-070610.log`。正常終了。
全9音源のPCM形式、無音でないこと、ピークのクリッピングがないことも検査した。

次は機能を増やすより、初見プレイで「チャージ・回避・フィーバーの使いどころが伝わるか」と
「冒頭からボスまで単調にならないか」を確認して、配置・間・ボスの隙を小さく調整する。
